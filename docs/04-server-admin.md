# Сервер: настройка, данные, сборка

## Конфигурация `config/wowcraft.json`
Создаётся при первом запуске.

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `startAtMaxLevel` | true | новые персонажи сразу 80 уровня с экипировкой |
| `starterItemLevel` | 112 | уровень стартовой экипировки |
| `allowBots` | true | боты заполняют группы, рейды, арены, поля боя |
| `openWorldPvp` | false | игроки разных групп могут атаковать друг друга в открытом мире |
| `vanillaMobHealthScale` | 1.0 | множитель здоровья ванильных мобов в бою WoW |
| `vanillaDamageScale` | 0.6 | урон ванильных мобов (доля от их удара в % здоровья) |
| `xpRate` | 1.0 | множитель опыта |
| `freeClassChange` | true | смена класса в любой момент вне боя |
| `maxPartySize` / `maxRaidSize` | 5 / 20 | размеры групп |
| `battlegroundTeamSize` | 5 | игроков в команде на поле боя |
| `instantReleaseInInstances` | false | можно сразу отпустить дух |
| `seed` | 0 | фиксированный seed боя (0 — случайный) |

## Данные
* `<мир>/wowcraft/players/<uuid>.json` — профиль персонажа (класс, таланты, панели, валюты, ключ, лучшие ключи, Хранилище, локи, PvP).
* `<мир>/wowcraft/world.json` — таблица лидеров M+, рейтинги.
* Экипировка в стандартных слотах хранится в инвентаре Minecraft (NBT `wow`), дополнительные слоты — в профиле.
* Автосохранение каждые 5 минут, при выходе игрока и остановке сервера.
* Измерение `wowcraft:instances` — служебное (пустота); инстансы строятся и стираются автоматически, его можно не бэкапить.

## Сборка из исходников
```
./gradlew :core:test          # тесты ядра (симуляции подземелий, M+, рейда, PvP)
./gradlew :fabric:build       # jar мода в fabric/build/libs/
./gradlew :fabric:runSmoke    # безголовый сервер: строит подземелье, спавнит NPC и ботов, бой, арена, выход
./gradlew :fabric:runClientSmoke  # клиент по сценарию: создание мира, выбор класса, все окна, подземелье с ботами,
                                  # ключ M+, арена 3х3, перезагрузка мира; скриншоты в fabric/run-client/screenshots
```
В CI оба теста запускаются на каждый пуш (клиент — под виртуальным дисплеем Xvfb). Артефакт **client-smoke** содержит
журнал и ~20 скриншотов интерфейса (HUD, окна, бой, трекер M+, арена) — удобно смотреть, как мод выглядит, не запуская игру.
Требуется JDK 21+ для Gradle/Loom (CI использует 25), байткод мода — Java 17.

### Сеть в облачной среде разработки
Хосты `maven.fabricmc.net`, `libraries.minecraft.net`, `piston-meta.mojang.com`, `piston-data.mojang.com`,
`resources.download.minecraft.net` должны быть доступны для локальной сборки Fabric-модуля. Если они заблокированы,
модуль собирается в GitHub Actions (workflow `build`), а ядро — локально с `-PcoreOnly`.

### Где взять jar
GitHub → Actions → workflow **build** → последний успешный запуск → артефакт **wowcraft-mod**.
