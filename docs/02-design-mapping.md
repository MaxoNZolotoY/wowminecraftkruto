# Как системы WoW перенесены в Minecraft

Этот документ — «карта соответствия»: что из [разбора WoW](01-wow-gameplay-analysis.md) реализовано, как и с какими
упрощениями. Цифры взяты из кода (`core/`), их легко менять.

## Архитектура

```
core/  (чистая Java 17, без Minecraft)           fabric/  (Fabric 1.20.1)
  combat/   движок боя: юниты, касты, ауры,          main/   McPlatform — реализация Platform:
            урон/лечение, угроза, DR, зоны                   сущности, миры, блоки, инвентарь, сеть
  content/  13 классов, 39 спеков, таланты,                  WowNpcEntity — «тело» NPC/бота/питомца
            предметы, подземелья, рейд, PvP-карты            ServerHooks — урон ванилы, смерть, вход
  npc/      шаблоны NPC, мозги, энкаунтеры,                  WowItems — предмет WoW ⇄ ItemStack (NBT)
            скрипты боссов, телеграфы                client/ HUD, экраны, управление, рендер,
  game/     GameServer: инстансы, M+, группы,                телеграфы, цифры урона
            поиск группы, боты, PvP, награды
  net/      протокол S2C/C2S (JSON по каналу wowcraft:main)
```

Всё правило-определяющее живёт в `core` и покрыто тестами, в том числе сквозными симуляциями (бот-группа проходит
подземелье, ключ M+, рейд, арену и поля боя на «фейковой» платформе). Fabric-слой только «рисует и двигает».

## Персонаж
| WoW | Мод |
|-----|-----|
| Уровни 1-80 | есть (опыт за убийства, подземелья); по умолчанию `startAtMaxLevel = true` — сразу 80 для игры с друзьями |
| 13 классов / 39 спеков | все, с ресурсами, ротациями, мастерством |
| Роли | танк / лекарь / ближний / дальний бой; бот-ИИ по ролям |
| Таланты класса / спека / героические | деревья 3×3 + выбор из 2 героических; ворота 2 очка на ряд; очки на 10/20/…, 15/25/…, героика с 70 |
| Смена спека | вне боя, в любой момент (`freeClassChange`) |

## Бой
| WoW | Мод |
|-----|-----|
| Здоровье | у юнита «виртуальное» здоровье WoW; сердечки Minecraft показывают **процент** |
| GCD, очередь заклинаний | 1.5 сек с ускорением скоростью, окно очереди |
| Касты / поддерживаемые / усиливаемые | все три; движение сбивает касты (кроме «на ходу») |
| Прерывания, школы магии | есть, блокировка школы |
| Контроль и DR | оглушение/страх/немота/корни/замедление…; DR 100/50/25/иммун, сброс 18 с (только для игроков и ботов) |
| Угроза, провокация | таблицы угрозы у NPC; провокации; смена танков на боссах |
| Ауры, проки, пандемия, рассеивание | полная система аур с триггерами и типами рассеивания |
| Поглощения, щиты | есть |
| Наземные зоны (Освящение, Метель…) | `GroundArea`, отрисовываются кругами на земле |
| PvP-модификатор урона | ×0.55 между игроками/ботами |
| Ванильные мобы | при первом бою получают юнит со здоровьем WoW-масштаба; их удары переводятся в % от здоровья |

**Ввод.** Клавиша **R** включает *боевой режим*: цифры 1-9, 0, -, = применяют способности панели вместо смены слота хотбара.
Цель — сущность под прицелом (дальность до 45 блоков) или текущая цель (**G** — перебор врагов). Левый клик по врагу =
выбрать цель + автоатака (ванильный урон отключён для персонажей с классом).

## Экипировка
| WoW | Мод |
|-----|-----|
| 16 слотов | голова/грудь/ноги/ступни/правая/левая рука — **настоящие слоты Minecraft**; шея, плечи, спина, запястья, кисти, пояс, 2 кольца, 2 аксессуара — «дополнительные» слоты (ПКМ предметом — надеть, окно персонажа **K** — снять/улучшить) |
| ilvl и бюджет | бюджет ∝ ilvl^1.5; доли слотов как в WoW |
| Треки улучшения | Исследователь 100 / Искатель 110 / Ветеран 120 / Чемпион 130 / Герой 140 / Миф 150; +3 за ранг |
| Валюты | золото, камни доблести, 4 вида гербов, честь, завоевание |
| Тир-сеты | 13 сетов (по классу), бонусы 2/4 |
| Аксессуары | «по нажатию» (клавиша **U**) и пассивные проки |
| Адаптивная основная характеристика | да |
| Персональная добыча | шанс за босса + защита от невезения |

Предметы хранят данные WoW в NBT (`wow`), видны в подсказке: уровень, статы, трек, эффект, источник.
Внешний вид брони пока ванильный (кожа/кольчуга/железо, окраска по качеству).

## Подземелья и M+
* **8 подземелий** по 3 босса (24 скрипта): Глубины Мрачного Оплота, Святилище Разбитого Прилива, Цитадель Угольной Кузни,
  Ледяной оссуарий, Роща Увядания, Шпиль Хора Бездны (бой с советом из двух боссов), Гробницы Песчаной Бури,
  Гавань Железного Крюка (совет «Капитан и попугай»).
* Карты **генерируются** из описания комнат (вход, трэш-комнаты, коридоры, залы, комнаты боссов) в отдельном измерении
  `wowcraft:instances` в «слотах» 1024×1024; после закрытия инстанса блоки стираются.
* Сложности: обычная, героическая, эпохальная, **M+**.
* **M+**: ключ у игрока; Источник силы (ПКМ) или `/wow start`; отсчёт 10 сек с удержанием в стартовой комнате; таймер;
  силы противника (нужно 85% от всего трэша); смерти +5/+15 сек; скейлинг 1.07/ур. до +10, далее 1.10;
  модификаторы: Укреплённый/Тиранический, сезонные (Взрывной, Кровавый, Бушующий, Вулканический, Терзающий, Страдающий,
  Бесплотный, Опутывающий, Бурлящий, Сотрясающий, Некротический, Зловредный, Злобный…), Испытание претендента (+7),
  Пульсар/Вознесение Бездны (+12); оценка как Raider.IO; улучшение ключа +1/+2/+3; таблица лидеров сервера.
* Чекпоинты (после убитого босса), вайп → воскрешение у чекпоинта, боевые воскрешения (1 + 1/10 мин).

## Рейд
**Трон Расколотой Звезды** — 5 энкаунтеров (6 боссов): Первичный страж (смена танков, поглощение кругов, дроны),
Ткачи звёзд (совет: держать здоровье ровно, лунные лучи «разбегись», солнечная вспышка «соберись»),
Горвакс Пожиратель (смена танков, кислота, всасывание), Верховный маг Элтерис («прекратите каст!», зеркальные копии),
Ксал'зорит (3 фазы, коллапс, тёмная материя, нарастающая аннигиляция). Сложности LFR/обычная/героическая/эпохальная,
недельный лок, тир-сеты с боссов, вклад в Хранилище. Здоровье рейдовых боссов растёт с размером группы.

## PvP
* Арены 2х2/3х3/5х5 (стычки и рейтинговые), **Одиночная потасовка** (6 раундов, смена команд), поля боя
  **Захват флага** (до 3 захватов) и **Господство** (3 точки, до 600 очков). 3 карты арен и 2 поля боя.
* Подготовка 20-25 сек у ворот, ослабление на аренах (+1% каждые 10 сек), «Направленная атака» на флагоносца,
  волны воскрешения на полях боя, Медальон гладиатора, DR.
* Рейтинг Эло с MMR, честь (уровни чести), завоевание, вклад побед в Хранилище.
* Пустые места заполняются **ботами** через 10 сек (боты ориентируются на флаги/точки).

## Группы, поиск, боты
* Группа до 5 (`maxPartySize`), рейд до 20 (`maxRaidSize`), лидер, роли, проверка готовности.
* **Поиск подземелий** (роль-матчинг 1/1/3, через 20 сек — соратники-боты), **поиск рейда** (10 игроков, боты).
* **Заранее собранные группы** для ключей: выставить группу, заявки с ролью и рейтингом.
* **Боты**: полноценные персонажи (класс, спек, таланты, сгенерированная экипировка, питомцы), ИИ на основе APL спека:
  уходят из телеграфов, встают в поглощения, танки провоцируют, лекари лечат, бойцы бьют приоритетные цели.
  Экипировку бота видно на модели.

## Что упрощено по сравнению с WoW
* Таланты: 9 узлов на дерево вместо ~30-40 (но с теми же правилами).
* Модели NPC — заглушки (зомби/скелет/паук/ифрит с окраской и масштабом), иконки — цветные квадраты с инициалами.
* Боссы: 2-4 механики, а не 8-15.
* Нет профессий, аукциона, заданий открытого мира, «Дельв».
* Карты подземелий — процедурные коробки комнат, а не авторские локации.
