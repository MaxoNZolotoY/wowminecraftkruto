# Как играть

## Установка
1. Minecraft **1.20.1**, [Fabric Loader](https://fabricmc.net/use/) ≥ 0.15, **Fabric API** для 1.20.1.
2. Скачайте `wowcraft-*.jar` (артефакт `wowcraft-mod` из GitHub Actions → последний успешный запуск `build`) и положите в `mods/`
   **и у клиента, и на сервере** (мод нужен обеим сторонам).
3. Для игры с друзьями: выделенный сервер или «Открыть для сети» в одиночной игре.

## Первые шаги
1. Зайдите в мир — откроется **выбор класса** (или нажмите **K** → «Сменить класс», или `/wow class`).
2. По умолчанию персонаж сразу 80 уровня с комплектом экипировки (ilvl 112) и ключом M+.
3. Нажмите **R** — боевой режим. Цифры **1-9, 0, -, =** применяют способности панели. Золотая рамка подсказывает
   следующее заклинание ротации.
4. **N** — таланты, **K** — персонаж и книга заклинаний (перетаскивание способностей на панель: выбрать способность → ячейку).

## Управление
| Клавиша | Действие |
|---------|----------|
| R | боевой режим вкл/выкл |
| 1-9, 0, -, = | способности (в боевом режиме) |
| ЛКМ по врагу | выбрать цель + автоатака |
| G | следующий враг перед вами |
| K | персонаж, экипировка, улучшения, книга заклинаний |
| N | таланты |
| O | поиск группы: подземелья, рейды, M+, PvP, группа |
| J | Великое хранилище и рейтинг сервера |
| M | счётчик урона |
| H | лечебное зелье |
| U | аксессуар «по нажатию» |
| Z | отпустить дух (после смерти в подземелье) |
| Y | принять приглашение в группу |

Все клавиши меняются в «Настройки → Управление → WoWCraft».

## Игра с друзьями
* Пригласить: `/wow invite Ник` (или вкладка «Группа» в **O**); принять — **Y** или `/wow accept`.
* Не хватает танка/лекаря? `/wow bot tank`, `/wow bot healer`, `/wow bots` (заполнить группу).
* Войти в подземелье всей группой: **O → Подземелья →** выбрать → «Войти: Героический», или `/wow dungeon grimhold_depths heroic`.
* Поиск с незнакомцами/ботами: «Очередь» (через 20 сек недостающие роли займут боты).

## Эпохальный+ (M+)
1. Посмотреть ключ: `/wow key`.
2. Лидер с ключом: **O → Эпохальный+ → «Запустить мой ключ»** (или `/wow m+`). Группа телепортируется к Источнику силы.
3. ПКМ по **Источнику силы** (или `/wow start`) — 10 сек отсчёт, затем таймер.
4. Цель: убить всех боссов и набрать 100% сил противника до конца таймера. Смерти добавляют время.
5. Справа — трекер: таймер, пороги +2/+3, силы противника, боссы, смерти, модификаторы недели (`/wow affixes`).
6. Итог: сундук (предметы уровня ключа), гербы, рейтинг (`/wow score`), новый ключ, вклад в Хранилище, запись в таблицу лидеров (`/wow top`).

## Рейд
`/wow dungeon throne_of_the_shattered_star normal` (или heroic / mythic / lfr). Нужна группа-рейд: `/wow raid`, затем
`/wow bots` (до 10). Следите за таймерами босса справа и кругами на земле: красное/оранжевое — уйти, синее — собраться,
жёлтое — встать в круг нужному числу игроков.

## PvP
**O → PvP**: 2х2, 3х3, 5х5, Потасовка, Захват флага, Господство, Случайное поле боя. Флажок «Рейтинговые» — на рейтинг.
`/wow pvp 3v3 rated`. Пустые места займут боты через 10 сек.

## Полезные команды
`/wow help` — полный список. `/wow dungeons`, `/wow vault`, `/wow currency`, `/wow upgrade HEAD`, `/wow leave`, `/wow release`, `/wow reset`.
Операторы: `/wow gear 140`, `/wow setlevel 70`, `/wow givekey tidewrack_sanctum 10`, `/wow item trinket 150`, `/wow give VALORSTONES 500`, `/wow weekly`.
