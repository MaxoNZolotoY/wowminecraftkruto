# WoWCraft — World of Warcraft в Minecraft (Fabric 1.20.1)

Мод для игры с друзьями: 13 классов и 39 специализаций с талантами, экипировка с уровнями предметов и улучшениями,
8 подземелий (24 босса), **Эпохальный+** с ключами, таймером, модификаторами и рейтингом, рейд на 5 энкаунтеров,
арены (2х2, 3х3, 5х5, Одиночная потасовка) и поля боя (захват флага, господство), боты, заполняющие любые роли,
Великое хранилище и недельный цикл.

## Структура
* `core/` — игровая логика без Minecraft (бой, контент, инстансы, M+, PvP, боты) + тесты-симуляции.
* `fabric/` — адаптер Fabric: сущности, предметы, блоки, измерение инстансов, сеть, HUD, экраны, рендер.

## Сборка
```
./gradlew :core:test :fabric:build
```
Готовый jar — `fabric/build/libs/` или артефакт `wowcraft-mod` в GitHub Actions.
